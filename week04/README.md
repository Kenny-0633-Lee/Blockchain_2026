# 4주차 실습 가이드 — SHA-256 & 해시 함수 특성

**경북대학교 블록체인 기술 | ICAB0203-001**

---

## 학습 목표

- SHA-256의 5가지 특성 실험: 결정론적·단방향·눈사태 효과·충돌 저항성·의사난수성
- 눈사태 효과 수치 측정 (평균 ~50% 비트 변화)
- 블록 변조 시 해시 체인 전체가 붕괴됨을 직접 확인

---

## 실행

```powershell
uv run python week04/sha256_avalanche.py
```

별도 패키지 설치 없음 — Python 표준 라이브러리 `hashlib`만 사용

---

## 실험 구성

| 실험 | 내용 | 핵심 관찰 포인트 |
|------|------|-----------------|
| **1. 기본 동작** | 다양한 입력 → SHA-256 출력 | 대소문자 1자 차이도 완전히 다른 해시 |
| **2. 눈사태 효과** | 입력 미세 변경 → 비트 변화율 측정 | 평균 ~50% 비트 변화 |
| **3. 단방향성** | 1,000회 무작위 대입 시도 | 역산 불가능성 체감 |
| **4. 부분 충돌 탐색** | 앞 N자리 0 조건 → 시도 횟수 측정 | PoW 난이도 원리 체험 |
| **5. 블록 변조** | 1개 블록 데이터 변경 → 연쇄 붕괴 | 불변성 원리 시각적 확인 |

---

## 예상 출력 (실험 2)

```
  변형 입력             | 변경 설명               | 비트차이 | 변화율
  Blockchain           | 첫 글자 대문자화         | 127비트  | 49.6%
  blockchain!          | 끝에 '!' 추가            | 134비트  | 52.3%
  ...
  평균 변화율: 50.8%  (이상적 눈사태 효과 = 50%)
```
