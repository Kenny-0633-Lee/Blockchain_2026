## 🎯 학습 목표

- SHA-256의 Avalanche Effect(눈사태 효과)를 수치로 확인한다

- AES-256-CBC 모드로 데이터를 암호화하고 복호화한다

## 🔑 핵심 개념 요약

### 해시 함수의 4가지 성질

| 성질 | 의미 | 코드에서 확인 |
|------|------|--------------|
| 결정론성 | 같은 입력 → 항상 같은 출력 | PART 1 |
| Avalanche Effect | 1비트 차이 → 출력 ~50% 변화 | PART 1 |
| 단방향성 | 해시 → 원본 역산 불가능 | PART 2 |
| 충돌저항 | 같은 해시 두 입력 찾기 불가 | (이론) |

### AES-CBC 구조

```
평문 블록1  평문 블록2  평문 블록3
    ↓           ↓           ↓
  XOR(IV)    XOR(암호1)  XOR(암호2)
    ↓           ↓           ↓
  AES 암호화  AES 암호화  AES 암호화
    ↓           ↓           ↓
  암호문1    암호문2    암호문3
```

- **대칭키**: 암호화와 복호화에 동일한 키 사용
- **IV(초기 벡터)**: 동일 평문이 동일 암호문이 되지 않도록 랜덤화

### HMAC

```
HMAC = Hash(비밀키 || Hash(비밀키 || 메시지))
```

메시지 + 공유 비밀키로 생성. 수신자는 동일 키로 재계산하여 무결성 검증.

## 📊 PART별 확인 포인트

### PART 1: Avalanche Effect
- 비트 차이가 **256비트 중 약 50%** (128비트 내외)인지 확인
- 마침표 하나 차이만으로 해시가 완전히 달라짐을 육안으로 확인

### PART 2: 단방향성
- 10만 번의 무작위 시도에서 목표 해시를 찾지 못함을 확인
- `❌ 발견 실패 — 단방향성 확인` 메시지 확인

### PART 3: AES-CBC
- 평문과 복호화 결과가 `✅` 일치하는지 확인
- 동일 평문도 IV가 다르면 다른 암호문이 생성됨 확인

### PART 4: HMAC
- 변조된 메시지: `❌ 아니오 — 변조 감지` 확인
- 잘못된 키: `❌ 아니오 — 키 불일치 감지` 확인
