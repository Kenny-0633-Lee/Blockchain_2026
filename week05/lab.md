## 🔑 핵심 개념 요약

### BIP-39 전체 흐름

```
[엔트로피 128비트]
       ↓
[체크섬 추가 → 132비트]
       ↓
[2048 단어 사전에서 12단어 선택]
       ↓ PBKDF2-HMAC-SHA512 (2048회 반복)
[시드 512비트]
       ↓
[개인키 (시드 앞 32바이트, 교육용 단순화)]
       ↓
[ECDSA 키쌍 (secp256k1)]
```

### Bitcoin 주소 도출 (5단계)

| 단계 | 연산 | 결과 |
|------|------|------|
| 1 | SHA-256(공개키) | 32바이트 |
| 2 | RIPEMD-160(step1) | 20바이트 |
| 3 | 버전 바이트 + step2 | 21바이트 (Testnet: 0x6F) |
| 4 | SHA256d(step3) 앞 4바이트 = 체크섬 | 4바이트 |
| 5 | Base58Check(step3 + step4) | m 또는 n으로 시작하는 주소 |

### Bitcoin vs Ethereum 주소

| | Bitcoin | Ethereum |
|--|---------|----------|
| 해시 | SHA256 + RIPEMD160 | Keccak-256 |
| 인코딩 | Base58Check | 16진수 |
| 접두사 | m/n (Testnet), 1 (Mainnet) | 0x |
| 길이 | 25~34자 | 42자 (0x + 40자) |

## 📊 PART별 확인 포인트

### PART 1: BIP-39 니모닉
- 12단어가 영어 단어로 출력되는지 확인
- 시드(64바이트)가 출력되는지 확인

### PART 2: ECDSA 키쌍
- 개인키 32바이트(64자리 16진수) 확인
- 압축 공개키가 02 또는 03으로 시작하는지 확인

### PART 3: Bitcoin 주소
- 5단계 변환 과정 확인
- 결과 주소가 **m 또는 n으로 시작**하는지 확인 (Testnet 기준)

### PART 4: Ethereum 주소
- 결과 주소가 **0x로 시작하는 42자리**인지 확인

### PART 5: ECDSA 서명
- 정상 서명: `✅ 유효` 확인
- 변조 메시지: `❌ 실패 — 변조 감지 성공` 확인
- 잘못된 공개키: `❌ 실패 — 키 불일치 감지` 확인
