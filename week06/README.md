# 6주차 실습 가이드 — Proof of Work 채굴 시뮬레이터

**경북대학교 블록체인 기술 | ICAB0203-001**

---

## 학습 목표

- PoW 해시 퍼즐(Nonce 탐색) 원리 구현 및 시각화
- 난이도 증가에 따른 채굴 시간의 기하급수적 증가 관찰
- 30회 반복 실험으로 기대 탐색 횟수 vs 실측값 비교
- PoW vs PoS 메커니즘 비교 이해

---

## 실행

```powershell
uv run python week06/pow_simulator.py
```

별도 외부 패키지 없음 — `hashlib`, `time`, `statistics`만 사용

> ⚠️ 난이도 5 도달 시 수십 초 소요될 수 있습니다. 기다려주세요.

---

## 데모 구성

| 데모 | 내용 |
|------|------|
| **1. 기본 채굴** | 난이도 4 단일 블록 채굴, H/s 측정 |
| **2. 난이도별 시간** | 난이도 1~5 채굴 시간 표로 비교 |
| **3. 5블록 체인** | 연속 채굴로 블록체인 구성 |
| **4. 통계 실험** | 30회 반복 → 기댓값 vs 실측 평균 비교 |
| **5. PoW vs PoS** | 두 합의 메커니즘 개념 비교 |
