## 🎯 학습 목표

- PoW의 원리: 목표값 이하의 해시를 찾을 때까지 Nonce를 증가시키는 반복 작업
- 난이도 1 증가 시 예상 시도 횟수가 약 16배 증가함을 수치로 확인
- 블록 1개 변조가 이후 모든 블록의 재채굴을 요구함을 확인
- 비트코인의 2016블록 난이도 조절 메커니즘의 원리 이해

## 🔑 핵심 개념 요약

### PoW 채굴 과정

```
블록 데이터 + Nonce(0)  →  SHA-256  →  해시값
해시값이 목표 이하?     →  NO  →  Nonce++
                        →  YES →  블록 완성! 보상 수령
```

### 난이도와 시도횟수의 관계

| 난이도 | 목표 조건 | 가능한 해시 비율 | 평균 시도횟수 |
|--------|-----------|----------------|--------------|
| 1 | `0...` | 1/16 | ~16 |
| 2 | `00...` | 1/256 | ~256 |
| 3 | `000...` | 1/4,096 | ~4,096 |
| 4 | `0000...` | 1/65,536 | ~65,536 |
| 5 | `00000...` | 1/1,048,576 | ~1,048,576 |

> 난이도 1 증가 = 16배 (16진수 한 자리 = 2^4)

### Bitcoin 난이도 조절

```
2016블록 생성 시간 목표: 2주 (= 10분 × 2016)
실제보다 빠르게 생성됨 → 난이도 ↑
실제보다 느리게 생성됨 → 난이도 ↓
```

## 📊 PART별 확인 포인트

### PART 1: Nonce와 해시 변화
- Nonce 0~9에서 10개 해시값이 모두 다른지 확인
- 그 중 0으로 시작하는 해시가 있는지 확인 (확률 1/16)

### PART 2: 난이도별 채굴 시간 ← **제출 필수**
- 난이도 1~5 각각의 시도횟수와 소요시간 확인
- 난이도 증가에 따른 배율이 ~16배인지 확인

### PART 3: 블록 변조 재채굴
- 변조 후 블록[1]과 블록[2]를 모두 재채굴해야 함을 확인
- 총 재채굴 비용이 원래보다 큰지 확인

### PART 4: 난이도 자동 조절
- 블록 생성이 너무 빠르면 `▲ 난이도 증가`, 느리면 `▼ 난이도 감소` 확인
